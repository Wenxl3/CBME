# R scripts for the main manuscript
The R scripts to conduct simulation experiments and generate all figures and tables in the main manuscript.

Structure each folder with two subdirectories: `Code`, containing R scripts for generating figures and tables; and `Result`, containing the corresponding output figures and tables.

## Files:

- **FIG1:**

  The Monte Carlo simulation under the naive Entropy Balancing (EB) framework to assess the impact of measurement error on covariate balance, parameter estimation, and treatment effect estimation.
- **FIG2:**

  The Monte Carlo simulation to assess the performance of naive and corrected EB methods in covariate balancing, using absolute standardized mean differences (ASMD) as the outcome metric.
- **TAB1:**

  The Monte Carlo simulation for ATT estimation using the naive EB, CEB, BCEB, CEB-HL, and CEB-HW methods.
