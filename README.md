# Covariate Balancing with Measurement Error: R Code for Simulation

This repository contains R code for the manuscript titled "Covariate Balancing with Measurement Error" by Xialing Wen and Ying Yan. The code includes simulation studies to demonstrate the covariate balancing methods proposed in the paper.

## Files:
- **Simulation:** R scripts for conducting Monte Carlo simulations to evaluate the performance of our proposed correction techniques under different scenarios involving measurement error.
  - **Main:** R scripts to conduct simulation experiments and generate all figures and tables in the main manuscript.
  - **Supplementary:** R scripts to conduct simulation experiments and generate all figures and tables in the supplementary material.

## Usage:
- To run the simulations, execute the corresponding R scripts in the folder.
